# p5 
para ejecutar el proyecto:
1.- git clone https://github.com/Ruth-ZS/proyecto.git

2.- tener reno instalado
verificar con 
deno --version

si no esta, instalar con 
iwr https://deno.land/install.ps1 -useb | iex

luego de la instalacion, Reinicia Visual Studio Code

para ejecutar ahora el main:
1. Asegúrate de estar en la carpeta donde está main.ts
2. Ejecuta main.ts con Deno: deno run --allow-env main.ts
(debes tener el .env para poder conectarte, este no esta en el repositorio por temas de seguridad)
